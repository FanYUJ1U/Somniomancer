# Contributing

Thank you for helping improve Somniomancer.

## Useful contributions

- Report a repeatable generation failure with the six-field brief and a short description of the result.
- Propose a narrow rule change that improves composition, hierarchy, typography, or texture control.
- Add an original, non-infringing example that demonstrates a transferable visual principle.
- Improve wording, translation, or accessibility without changing the intended visual system.

## Before submitting

- Keep the subject non-photorealistic and structurally transformed.
- Do not reintroduce global grain, distressed-paper texture, random speckles, or all-over halftone as the default archival language.
- Do not add copyrighted third-party artwork, logos, characters, or unlicensed fonts.
- Keep your contribution non-commercial and retain the project attribution and license.
